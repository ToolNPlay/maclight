## ✨ Key Features

- **⚡ Menu Bar Companion:** Quick-access menu bar meter with 1-click RAM purge, live disk storage meter, and trash empty shortcut.
- **👯 Smart Duplicate Files Finder:** Bit-for-bit SHA-256 duplicate detection with instant side-by-side **live preview** for Photos, 4K Videos, Audio, and Documents.
- **🛡️ Developer & Project Safe Mode:** Built-in safeguards automatically protect Xcode projects, Git repositories (`.git`), build artifacts (`DerivedData`, `.swiftmodule`), and package caches (`node_modules`, `Pods`).
- **🧹 App Residual Leftovers:** Scans deep inside `~/Library` to completely wipe hidden orphaned caches, preferences, and crash logs left behind by deleted applications.
- **🚀 Startup Items & Daemons Manager:** Enable, disable, or delete startup background launch agents and daemons (`LaunchAgents`, `LaunchDaemons`).
- **🔒 Privacy & Traces Wiper:** Instantly wipe terminal command histories, Finder recent items, clipboard data, and quick-look caches.
- **📁 Visual Disk Footprint:** Interactive DaisyDisk-style visual bar chart breakdown of your largest space hogs.
- **🔋 Battery Health & Hardware Telemetry:** Real-time Apple Silicon CPU performance, battery health cycle count, and thermal state monitoring.

## 🚀 How to Install & Open (First Time Setup)

Because MacLight is distributed freely outside the Mac App Store:

1. **Download** the [`MacLight-v1.0.0.dmg`](https://github.com/toolnplay/maclight/releases/latest/download/MacLight-v1.0.0.dmg) installer.
2. Double-click the `.dmg` and **drag MacLight into your Applications folder**.
3. **First launch**:
   - In Finder -> `Applications`, **Right-Click** (or `Control` + Click) **MacLight**.
   - Select **Open** from the context menu.
   - Click **Open** in the confirmation dialog.
   *(You only need to do this once — macOS will remember your permission!)*

## 🔄 Automatic Updates

MacLight automatically checks for updates in the background. When a new version is released, you will receive an in-app prompt with release notes and a direct download button.

You can also manually check anytime via **MacLight Menu Bar > Check for Updates** or in the **About** window.
